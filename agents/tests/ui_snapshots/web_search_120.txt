 worktree guide                                                                                                        ▕
 Claude Code Worktrees: Parallel Sessions Without Conflicts                                                            ▕
                                                                                                                       ▕
 The default location is .claude/worktrees/<name>/ under the repository root. Running claude --worktree                ▕
 <name> creates that directory and a new branch named worktree-<name>. The official docs say to put                    ▕
 worktrees somewhere else, configure a WorktreeCreate hook.                                                            ▕
 • Naming: If you omit the name, Claude generates one such as bright-running-fox.                                      ▕
 • Base branch: Worktrees branch from the remote default branch, and fall back to your current local HEAD if           ▕
   no remote is configured or the fetch fails. Setting worktree.baseRef to "head" changes this to local
   HEAD.
 • Trust prompt: Before using --worktree interactively in a directory for the first time, accept the
   workspace trust dialog.
 • Gitignore: Sources recommend adding .claude/worktrees/ to .gitignore so worktree contents don't show up…
